# Age of the Saxons

A browser survival & settlement game. Land on an England-sized island, survive,
fell timber and dress stone, raise a settlement, command a crew of settlers, and
share the island with its Anglo-Saxon-era people.

**▶ Play in your browser: https://schappiplays.github.io/age-of-the-saxons/**

Press **H** in-game for the controls.

*This repository holds only the compiled build so the game can be served from
GitHub Pages.*
